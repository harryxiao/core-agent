多模态输入增量规格，将 UI 输入模态从文本扩展为图像与语音，统一路由到具备对应能力的模型处理，对齐 OpenAI Agents voice / Manus 图像输入。

## ADDED Requirements

### Requirement: 多模态输入
系统 SHALL 支持图像与语音等多模态输入的接入，并统一路由到具备对应能力的模型处理。

#### Scenario: 图像输入理解
- **GIVEN** 用户在 UI 中附加图片（截图/照片）
- **WHEN** 发起会话
- **THEN** 图片经统一输入管道交给具备视觉能力的模型理解，结果并入上下文

#### Scenario: 语音输入转写
- **GIVEN** 用户以语音方式输入
- **WHEN** 语音被采集
- **THEN** 系统先转写为文本再进入统一内核，必要时保留原始音频引用

#### Scenario: 模态能力缺失降级
- **GIVEN** 当前配置的模型不具备某模态理解能力
- **WHEN** 用户提交该模态输入
- **THEN** 系统明确提示不支持并给出可替换建议，不静默丢弃输入
