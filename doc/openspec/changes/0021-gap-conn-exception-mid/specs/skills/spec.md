技能执行超时与资源上限：执行超时中断回收资源，资源超限熔断，不阻塞主循环。（来源：架构查漏补缺探索结论，2026-09-22）

## ADDED Requirements

### Requirement: 超时与资源上限
系统 SHALL 对技能执行设置超时与资源上限，超时/超限时中断执行并回收资源，不阻塞主循环。

#### Scenario: 执行超时中断
- **GIVEN** 一个技能执行时间超过设定上限
- **WHEN** 超时触发
- **THEN** 中断该技能执行并回收资源，返回 SKILL_TIMEOUT，不影响主循环

#### Scenario: 资源超限熔断
- **GIVEN** 一个技能的资源占用（内存/并发）超过上限
- **WHEN** 资源超限
- **THEN** 熔断该技能执行并回收资源，告警，避免拖垮主循环
