实时语音输出补齐 Core-Agent 多模态语音交互的输出侧闭环：将内核生成的文本回复以流式 TTS 合成语音实时播报，支持播报过程中打断（barge-in）与语音/文本上下文双向引用，CLI/Web/Desktop 三模行为一致（来源：research_findings.md，2026-09-21）。

## ADDED Requirements

### Requirement: 实时语音输出
系统 SHALL 支持将内核生成的文本回复以流式 TTS 合成语音实时播报，允许用户在播报过程中打断（barge-in），并保留语音与文本会话上下文的双向引用。

#### Scenario: 流式 TTS 播报
- **GIVEN** 内核产生分片文本回复
- **WHEN** 用户开启了语音播报
- **THEN** 分片文本被增量送入 TTS 合成并连续播报，不等待整段回复完成

#### Scenario: 用户打断（barge-in）
- **GIVEN** 语音播报正在进行
- **WHEN** 用户开口说话或按下打断键
- **THEN** 系统立即停止当前播报并转入语音输入处理，被打断的文本不丢失并保留在会话记录中

#### Scenario: 语音上下文引用
- **GIVEN** 会话中既有语音输入又有语音播报
- **WHEN** 用户后续引用或追问先前内容
- **THEN** 语音与文本共享同一会话记录可相互引用，必要时保留原始音频引用
