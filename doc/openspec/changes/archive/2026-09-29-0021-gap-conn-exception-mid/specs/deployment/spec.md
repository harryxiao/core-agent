## ADDED Requirements

### Requirement: 客户端断线与会话清理
系统 SHALL 在 Harness Host 客户端断线或超时后完成会话清理与资源释放：检测客户端断开（含心跳/超时判定），回收该客户端会话与连接资源，且不影响其他并发客户端的会话。

#### Scenario: 客户端断线清理
- **GIVEN** 一个 Web/Desktop 客户端已接入 Harness Host 并建立会话
- **WHEN** 该客户端网络断线或异常退出
- **THEN** Host 检测到断线后清理该客户端的会话与连接资源，其他并发客户端的会话不受影响

#### Scenario: 连接超时回收
- **GIVEN** 客户端长时间无活动
- **WHEN** 超过连接超时（timeout）阈值
- **THEN** 判定连接失效并释放该会话与连接资源，避免资源泄漏
