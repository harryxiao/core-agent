# Design 0277 — 记忆内容分区权重（tags 三档）

## D1 加性一维，而非乘性

- `relevance = 0.5·sim + 0.2·layer_priority + 0.15·tier`，`tier ∈ {+1, 0, −1}`。
- 理由：`rank` 的乘性部分（时间/复用/重要度）已经参与调制，再叠一个乘性档位会让「高频复用的
  过程日志」压过「关键决策」；加性项与 `layer_priority` 同量纲、可解释，且不改变 `rank` 的
  既有结构（`relevance × 调制项`）。
- **默认档取零偏移**（初版取 `0.5` 已证伪）：`rank = relevance × (1+log1p(reuse)) × …`，
  正常量偏移 `+0.075` 会抬高全部无标签条目的基数，再经复用因子放大 ⇒ 1 万条基准中高复用
  填充项反超 gold，**recall@5 实测 1.000 → 0.45**。取 `{+1,0,−1}` 后未分档条目得分逐位不变。
- 系数 `_W_TIER = 0.15`：高档对默认档 +0.15、低档 −0.15；与层差（L3 vs L2 = 0.04、
  L0 vs L2 = 0.08）同量级偏强，但只作用于显式打标条目 ⇒ **只破接近的并列，不压倒真实相关性**
  （sim 仍占主导，上限 0.5）。

## D2 三档与标签约定

- 高档：`{"milestone", "decision"}`；低档：`{"log", "transcript"}`；默认：其余（含无标签、
  未知标签）。
- **冲突 ⇒ 高档优先**（同时带 `milestone` 与 `log` 的条目按关键内容处理；宁可多留不可漏掉）。
- **精确匹配、区分大小写**（约定小写）：避免 `"Milestone"` 之类拼写漂移静默改变排序；未知标签
  ⇒ 默认档，故新增标签不会意外降权。
- 档位判定只看 `tags`，不看 `source` / `kind`：来源到内容的语义映射留给写入方显式打标，
  避免「episodic 一定是日志」这类不可控推断。

## D3 默认开启与兼容面

- 用户裁决：缺省开启、无配置开关。默认档**零偏移** ⇒ 未分档条目得分与分档前逐位相同；
  层优先级 / BM25 / 时间 / 复用 / 重要度语义不变。
- 既有精确值断言（`test_memory_lexical_scoring.py`）数值不变（默认档零偏移）；其余排序类
  测试不受影响（既有语料无 `milestone`/`decision`/`log`/`transcript` 标签）。
- `0261`（26 条）与 `0275`（1 万条）基准语料无分档标签 ⇒ recall/MRR 应逐项不变；1 万条延迟
  因每候选多一次标签检查而略增，仍须 <100ms 中位（`0276` 基线 85.8ms）。

## D4 测试设计

- `tests/test_memory_tiers.py`（新）：
  - **三档定序**：同内容 / 同层 / 同时间戳，仅 tags 不同 ⇒ `relevance` 高 > 默认 > 低；
    `rank` 同步定序。
  - **冲突与未知**：`["milestone", "log"]` ⇒ 高档；`["unknown"]` ⇒ 默认；`["Milestone"]` ⇒ 默认。
  - **同档不变**：两个未分档条目仅层不同 ⇒ 排序由 `layer_priority` 决定（与加入分区前一致）。
  - **端到端**：`MemoryStore.read` 三条同内容、tags 三档 ⇒ 返回顺序 高→默认→低。
- `test_memory_lexical_scoring.py`：数值断言不变（默认档零偏移），仅更新注释口径。
- 基准：`0261` / `0275` 阈值与语料不改，只确认全绿与延迟报告。

## 反证

1. 摘掉 `relevance` 的 `tier` 项 ⇒ 三档定序用例红。
2. 把高低档优先级反转（低档先判）⇒ 冲突用例红。
3. 未知标签按低档处理 ⇒ 未知用例红。
复原后 `md5sum` 一致。

## 已知局限

- 档位依赖写入方**显式打标**；未打标的内容（包括现有库）全部落默认档 ⇒ 收益取决于标签纪律。
- 四个标签名是**开放约定**的一小撮，新增档位需改代码（无配置）；`milestone` 同时被 notes
  模块用作笔记 tag，但笔记不是 `MemoryEntry`，两域互不影响（同名不同域，已在文档注明）。
- 加性权重只破并列；高相关低档条目仍可能排在低相关高档之前（有意：相关性优先）。
- 不改变 `_PRESERVE_TAGS`（`failure`）等既有 tag 语义；`rank` 现会读取 tags（仅四个档位标签）。
