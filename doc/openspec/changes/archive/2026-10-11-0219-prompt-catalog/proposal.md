# Proposal 0219 — 内置提词总表 ＋ pin 补 3 条（测试/文档，规格中性）

## Why（缺口）

`0215`/ADR-0205 把 **9 条**核心 prompt 头逐字 pin，并在 ADR-0205「局限②」登记：**⑧ 情景归纳器
（`0218` 才新增）、⑪ 源码修补者、⑫ 候选审查者**三条 prompt 头**未纳入**，⑬ 宠物人格为动态拼接、
未纳。同时，全仓 prompt 散落在 **12 个模块**里，**没有一处集中可查阅** —— 「这条提词写了什么、
在哪、有没有被 pin」只能逐个 grep。

## What Changes

**零 `src/` 改动**。两件：

1. **扩 pin**：`tests/test_prompt_pinning.py` 增 4 用例（3 条逐字头 ⑧⑪⑫ ＋ 1 条情景归纳 builder
   结构不变量）⇒ 该文件 12 → **16** 用例，仓覆盖 **9 → 12** 条。
2. **新文档**：`doc/03-interfaces/prompts.md`「内置提词总表」—— 13 条 prompt 的**原文逐字** ＋
   落点 `文件:行` ＋ 输出契约 ＋ 面别归类 ＋ 动态拼接部分 ＋ pin 状态 ＋ 改动指引。

**pin 的两类锚**（承 `0215`）：逐字头（12 条）＋ 结构不变量（头恒首位 / 条目 `- ` 前缀 /
占位符解析 / 谓词白名单集合恒等 / 节选上界字面量）。

**规格中性判定**：pin 的是**实现细节**（模块私有常量），文档是对**既有** prompt 的镜像描述；
皆**既有行为的护栏/快照**而非新行为 ⇒ 无 spec delta，`.openspec.yaml` `skip_specs: true`
（沿 `0156`/`0189`/`0195`/`0199`/`0215` 先例）。

**文档的诚实性**：本表明写**「镜像是非真源」**—— 真源是各模块常量 ＋ pin 副本；改一条 prompt
须**三处同改**（模块常量 → pin 副本 → 本表），只改一处时 pin 测试转红。

## 显式不做

- **不**把 prompt 收拢进单一 `src/core/prompts.py`（会触及 ADR-0205「prompt 是实现细节、不外露」
  口径，且 pin 的「独立副本」意义减弱）。
- **不**把 prompt 改为配置/文件驱动（破既立口径，须独立 change）。
- **不** pin ⑬ 宠物人格（动态拼接、无稳定逐字锚）。
- **不**改任何 prompt 的**措辞**（本 change 仅补 pin ＋ 文档；措辞改动是**未来**动作，由本表指引）。
