# 主/子 Agent 视图标签栏（TUI + Web/Desktop）

## Why

编排任务运行时，子 Agent 的执行过程在 TUI 中只能通过 `/focus <子任务标识>` 进入，用户既看不到入口，
也不知道子任务标识；点击子任务折叠块只会展开详情，无法直接切到该子 Agent 的实时视图。Web/Desktop
任务区同样只列子任务与 `<details>` 详情，主聊天区没有主/子视图切换。

用户希望像 Claude Code 一样：聊天窗下方自动出现 `main` 与各 subagent（主题缩写）标签，单击即可把
主视图切到该 subagent 的实时详情，点 `main` 立即切回主 Agent 信息。

## What Changes

- **TUI**：时间线下方（输入区上方）新增标签栏 `main` + 当前/最近任务子任务（主题缩写）；点击标签
  切换既有主视图 ⇄ 焦点视图；点击子任务折叠块标题同样进入焦点视图。标签随开工/收尾更新状态，
  任务收尾保留终态快照，下一次 `task_started` / 会话切换重置。
- **Web/Desktop**：任务状态上提到 `App`，新增纯 reducer 与 `TaskTabs` / `SubtaskDetail` 组件；
  聊天区下方显示 `main` + 子任务标签，点击切为**只读**子任务详情（验收 / 里程碑 / 理由 / 结果节选），
  点 `main` 返回；任务区子任务行也可点击选中同一视图。收尾保留快照，下一次任务/会话重置。
- 两端均只使用既有 `task.*` 事件载荷，不新增后端端点/事件/配置键。

## Non-Goals

- 不新增子 Agent 消息通道、不接子 Agent 转录、不允许向子 Agent 发消息。
- 不自动把视图切到正在运行的子 Agent（只自动展示标签）。
- 不改变 `/focus`、`/main`、`F2` 的语义与忙态豁免。
- 不改 scheduler 事件载荷、不新增持久化。
